# 3. ประกอบหุ่นยนต์

หุ่นยนต์สองล้อ มีมอเตอร์สองตัว ล้อ caster ด้านหลังกันไม่ให้มันล้ม
แบตเตอรี่ motor driver และ ESP32

## ทำไมต้องมี motor driver?

ESP32 ทำงานที่ 3.3 V และขาของมันจ่ายกระแสได้แค่ไม่กี่มิลลิแอมป์ --
พอให้ LED ติดได้ แต่ไม่พอจะหมุนมอเตอร์เลย motor driver ทำหน้าที่เป็น
สวิตช์: ฝั่งหนึ่งรับสัญญาณเล็ก ๆ จาก ESP32 อีกฝั่งจ่ายไฟจากแบตเตอรี่
ไปให้มอเตอร์

## การต่อสาย

| Motor driver | ESP32 | หน้าที่ |
|---|---|---|
| IN1 | GPIO 27 | ทิศทางมอเตอร์ซ้าย (A) |
| IN2 | GPIO 26 | ทิศทางมอเตอร์ซ้าย (A) |
| ENA | GPIO 14 | ความเร็วมอเตอร์ซ้าย (A) (PWM) |
| IN3 | GPIO 25 | ทิศทางมอเตอร์ขวา (B) |
| IN4 | GPIO 33 | ทิศทางมอเตอร์ขวา (B) |
| ENB | GPIO 32 | ความเร็วมอเตอร์ขวา (B) (PWM) |
| GND | GND | **จำเป็นต้องต่อ** -- ดูด้านล่าง |

ตารางนี้ต้องตรงกับเลขขาที่อยู่ด้านบนของ
[motor.h](../firmware/include/motor.h) ถ้าคุณต่อสายต่างไปจากนี้ ให้แก้
`motor.h` ให้ตรงกัน -- ไม่อย่างนั้นล้อจะนิ่งเฉยโดยไม่มี error อะไรเลย
เพราะโค้ดกำลังสั่งขาที่ไม่ได้ต่ออะไรไว้

ถ้าใช้ **L298N** ให้ถอด jumper ที่ ENA และ ENB ออก ไม่อย่างนั้น ESP32
จะคุมความเร็วไม่ได้

ขั้ว `+` ของแบตเตอรี่ต่อเข้า `12V`/`VIN` ของ driver ขั้ว `-` ของแบตเตอรี่ต่อเข้า `GND` ของ driver

### สาย ground

GND ของ ESP32 กับ GND ของ motor driver **ต้อง**ต่อถึงกัน ถึงแม้ว่า
จะใช้ไฟคนละแหล่งก็ตาม "3.3 โวลต์" หมายถึง 3.3 โวลต์ *เมื่อเทียบกับ
ground* -- ถ้าสองบอร์ดไม่ได้ตกลงกันว่า ground อยู่ตรงไหน driver ก็จะ
แยก HIGH กับ LOW ไม่ออก หุ่นยนต์ที่กระตุกมั่ว ๆ เกือบทุกครั้ง
เป็นเพราะลืมต่อสายเส้นนี้

### ห้ามใช้ขาเหล่านี้

GPIO 0, 2, 12 และ 15 จะถูก ESP32 อ่านค่าตอนเปิดเครื่องเพื่อตัดสินใจว่าจะ
boot แบบไหน ถ้ามี motor driver ดึงขาพวกนี้อยู่ บอร์ดอาจจะไม่ start
เลยก็ได้ ขาในตารางด้านบนเลี่ยงขาพวกนี้ไว้แล้ว

### เสริม: เซนเซอร์อัลตราโซนิก (HC-SR04)

firmware ยังไม่ได้ใช้ แต่ถ้าคุณจะติดตั้ง: TRIG ต่อ GPIO 5,
ECHO ต่อ GPIO 18 ขา ECHO ของมันปล่อยไฟ **5 V** ซึ่งทำให้ ESP32
เสียหายได้ -- ให้ใส่วงจรแบ่งแรงดัน (voltage divider) ไว้ (1 kΩ จาก ECHO, 2 kΩ ลง GND,
แล้วเอาสัญญาณจากจุดตรงกลาง)

## ถัดไป

อย่าเพิ่งเขียนโค้ดอะไร บทที่ 4 จะ upload โปรแกรมทดสอบที่สั่งล้อ
ทีละข้าง เพื่อให้คุณเช็คสายทุกเส้นได้ก่อนจะเพิ่มอย่างอื่นเข้าไป
และในบทนั้นคุณจะวัดขนาดหุ่นยนต์แล้วตั้งค่า
`WHEEL_BASE` ด้วย
