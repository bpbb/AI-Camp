# 0. เตรียมเครื่องคอมพิวเตอร์

> **ทำบทนี้ให้เสร็จก่อนวันเรียน**
> การ build firmware ครั้งแรกต้องดาวน์โหลดของเยอะ ใช้เวลาประมาณ 10 นาที

## ภาพรวมของคู่มือ

คู่มือมี 7 บท ทำเรียงตามลำดับ:

| บท | เรื่อง | ใช้อะไรบ้าง |
|---|---|---|
| 1 | Terminal | คอมพิวเตอร์อย่างเดียว |
| 2 | Node และ topic | คอมพิวเตอร์อย่างเดียว |
| 3 | ประกอบหุ่นยนต์ | หุ่นยนต์อย่างเดียว |
| 4 | ทดสอบมอเตอร์ | หุ่นยนต์ + สาย USB (ยังไม่ใช้ WiFi) |
| 5 | micro-ROS | หุ่นยนต์คุยกับคอมพิวเตอร์ผ่าน WiFi |
| 6 | MQTT | ส่งคำสั่งอีกแบบหนึ่ง |
| 7 | ขับด้วยมือถือ | ทำหรือไม่ทำก็ได้ |

## สิ่งที่ต้องมี

- คอมพิวเตอร์ที่ลง **Ubuntu 24.04** (ใช้ ROS 2 Jazzy) หรือ **Ubuntu 22.04** (ใช้ ROS 2 Humble)

  ดูว่าเครื่องเป็นเวอร์ชันไหน:

```bash
lsb_release -ds
```

- โปรแกรม **VS Code**
- บอร์ด ESP32 และสาย USB ที่ **ส่งข้อมูลได้**
  (สายบางเส้นชาร์จไฟได้อย่างเดียว ถ้าใช้สายแบบนั้น จะ upload ไม่ได้ และไม่มี error บอกด้วย)

## ขั้นที่ 1: ติดตั้ง extension ใน VS Code

1. เปิดโฟลเดอร์ `~/AI-Camp` ใน VS Code
2. ถ้ามีหน้าต่างถามว่าจะติดตั้ง extension ที่แนะนำไหม ให้กด **Yes**
3. ถ้าไม่มีหน้าต่างถาม ให้ติดตั้งเองตามตารางนี้

| Extension | ใช้ทำอะไร |
|---|---|
| PlatformIO IDE | build โปรแกรมลงบอร์ด ESP32 |
| ROS | ช่วยเขียนโปรแกรม ROS 2 |
| Python | ช่วยเขียนโปรแกรม Python |

## ขั้นที่ 2: ติดตั้งโปรแกรมที่ต้องใช้

```bash
cd ~/AI-Camp
./scripts/setup_pc.sh
```

สคริปต์นี้ติดตั้งทุกอย่างที่ต้องใช้ให้เอง ใช้เวลาไม่กี่นาที และทำแค่ครั้งเดียวต่อเครื่อง

> ถ้าเห็นข้อความ `error: externally-managed-environment` ไม่ต้องตกใจ เป็นเรื่องปกติของ Ubuntu 24.04
> สคริปต์จัดการให้แล้ว **ห้ามติดตั้ง Python ใหม่เอง**

จากนั้นให้สิทธิ์ตัวเองในการ upload โปรแกรมลง ESP32 ผ่านสาย USB:

```bash
sudo usermod -aG dialout $USER
```

แล้ว **log out แล้ว log in ใหม่** (หรือ restart เครื่อง)
ถ้าข้ามขั้นนี้ ตอน upload จะเจอ error `Permission denied /dev/ttyUSB0`

## ขั้นที่ 3: บอก firmware ว่าเครื่องใช้ ROS 2 ตัวไหน

ดูว่าเครื่องมี ROS 2 ตัวไหน:

```bash
ls /opt/ros
```

ผลลัพธ์ที่ควรเห็น: `jazzy` (Ubuntu 24.04) หรือ `humble` (Ubuntu 22.04)

เปิดไฟล์ `firmware/platformio.ini` หาบรรทัดนี้ แล้วแก้คำหลัง `=` ให้ตรงกับที่เห็น:

```ini
board_microros_distro = humble   ; jazzy on 24.04, humble on 22.04
```

ถ้าแก้บรรทัดนี้ ต้องลบผล build เก่าทิ้งด้วย:

```bash
rm -rf ~/AI-Camp/firmware/.pio
```

## ขั้นที่ 4: build โปรแกรมฝั่งคอมพิวเตอร์

```bash
cd ~/AI-Camp/ros2_ws
colcon build
```

## ขั้นที่ 5: build firmware ไว้ล่วงหน้า

พิมพ์คำสั่งในโฟลเดอร์ `~/AI-Camp` (ไม่ใช่ในโฟลเดอร์ `firmware`):

```bash
cd ~/AI-Camp
./scripts/build_firmware.sh motortest
./scripts/build_firmware.sh microros
```

ทั้งสองคำสั่งต้องจบด้วยคำว่า `SUCCESS`

ผลลัพธ์ที่ควรเห็น (บรรทัดสุดท้าย):

```text
========================= [SUCCESS] Took 12.34 seconds =========================
```

ครั้งแรก `microros` จะช้ามาก ครั้งต่อไปจะเหลือไม่กี่วินาที

## ขั้นที่ 6: ตรวจเครื่อง

```bash
cd ~/AI-Camp
./scripts/check_setup.sh
```

ทุกบรรทัดควรเป็น **สีเขียว**

มีบรรทัดเดียวที่เป็นสีแดงได้ คือ `config.h says ..., this machine is ...`
เพราะเรายังไม่ได้ตั้งค่าหุ่นของทีม เราจะตั้งในบทที่ 5

> ค่าของทีม (เลขทีม, WiFi, IP) ยังไม่ต้องตั้งตอนนี้
> เลขทีมตั้งในบทที่ 2 ส่วนค่าอื่นตั้งในบทที่ 5
