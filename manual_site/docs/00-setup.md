# 0. เตรียมเครื่องคอมพิวเตอร์

> การ build firmware ครั้งแรกอาจใช้เวลานาน

## ภาพรวมของคู่มือ

คู่มือนี้มี 6 บท ให้ทำตามลำดับ:

| บท | เรื่อง | รายละเอียด |
|---|---|---|
| 1 | Terminal | ใช้คำสั่งพื้นฐานและตั้งค่า Environment |
| 2 | Node และ topic | รับส่งข้อมูลระหว่างโปรแกรมด้วย ROS 2 |
| 3 | ทดสอบมอเตอร์ | ตรวจสอบการต่อสายผ่าน USB โดยยังไม่ใช้เครือข่าย |
| 4 | micro-ROS | เชื่อมหุ่นยนต์เข้ากับ ROS 2 และขับด้วยคีย์บอร์ด |
| 5 | MQTT | ส่งคำสั่งผ่าน MQTT broker และ gateway |
| 6 | ขับหุ่นยนต์ด้วยมือถือ | ควบคุมหุ่นยนต์ด้วยแอปบนโทรศัพท์ |

## สิ่งที่ต้องมี

- คอมพิวเตอร์ที่ติดตั้ง **Ubuntu 24.04** (ใช้ ROS 2 Jazzy) หรือ **Ubuntu 22.04** (ใช้ ROS 2 Humble)

  เช็กว่าเครื่องเป็น Ubuntu เวอร์ชันไหน:

```bash
lsb_release -ds
```

- โปรแกรม **VS Code**
- บอร์ด ESP32 และสาย USB ที่ **ส่งข้อมูลได้**
  (สายบางเส้นชาร์จไฟได้อย่างเดียว ถ้าใช้สายแบบนี้จะ upload ไม่ได้ โดยไม่มี error แจ้งเลย)

## ขั้นที่ 1: ติดตั้ง extension ใน VS Code

1. เปิดโฟลเดอร์ `~/AI-Camp` ใน VS Code
2. ถ้ามีหน้าต่างถามว่าจะติดตั้ง extension ที่แนะนำไหม ให้กด **Yes**
3. ถ้าไม่มีหน้าต่างถาม ให้ติดตั้งเองตามตารางนี้

| Extension | ใช้ทำอะไร |
|---|---|
| PlatformIO IDE | build โปรแกรมสำหรับบอร์ด ESP32 |
| ROS | ช่วยเขียนโปรแกรม ROS 2 |
| Python | ช่วยเขียนโปรแกรม Python |

## ขั้นที่ 2: ติดตั้งโปรแกรมที่ต้องใช้

```bash
cd ~/AI-Camp
./scripts/setup_pc.sh
```

สคริปต์นี้จะติดตั้งทุกอย่างที่ต้องใช้ให้เอง ใช้เวลาไม่กี่นาที และรันแค่ครั้งเดียวต่อเครื่อง

> ถ้าเห็นข้อความ `error: externally-managed-environment` ไม่ต้องตกใจ เป็นเรื่องปกติของ Ubuntu 24.04
> สคริปต์จัดการเรื่องนี้ให้แล้ว **ห้ามติดตั้ง Python ใหม่เอง**

จากนั้นเพิ่มสิทธิ์ให้ user ของตัวเอง upload โปรแกรมลง ESP32 ผ่านสาย USB ได้:

```bash
sudo usermod -aG dialout $USER
```

จากนั้น **log out แล้ว log in ใหม่** (หรือ restart เครื่อง)
ถ้าข้ามขั้นนี้ ตอน upload จะเจอ error `Permission denied /dev/ttyUSB0`

## ขั้นที่ 3: บอก firmware ว่าเครื่องใช้ ROS 2 ตัวไหน

เช็กว่าเครื่องติดตั้ง ROS 2 ตัวไหนไว้:

```bash
ls /opt/ros
```

ผลลัพธ์ที่ควรเห็น: `jazzy` (Ubuntu 24.04) หรือ `humble` (Ubuntu 22.04)

เปิดไฟล์ `firmware/platformio.ini` หาบรรทัดด้านล่างนี้ แล้วแก้ค่าหลัง `=` ให้ตรงกับผลลัพธ์ข้างบน:

```ini
board_microros_distro = humble   ; jazzy on 24.04, humble on 22.04
```

ถ้าแก้บรรทัดนี้ ต้องลบไฟล์ build เก่าทิ้งด้วย:

```bash
rm -rf ~/AI-Camp/firmware/.pio
```

## ขั้นที่ 4: build โปรแกรมฝั่งคอมพิวเตอร์

```bash
cd ~/AI-Camp/ros2_ws
colcon build
```

## ขั้นที่ 5: build firmware

รันคำสั่งต่อไปนี้ในโฟลเดอร์ `~/AI-Camp`:

```bash
cd ~/AI-Camp
./scripts/build_firmware.sh motortest
./scripts/build_firmware.sh microros
```

ทั้งสองคำสั่งต้องจบด้วยคำว่า `SUCCESS`

ผลลัพธ์ที่ควรเห็น (บรรทัดสุดท้าย):

```text
========================= [SUCCESS] Took 12.34 seconds =========================
```

## ขั้นที่ 6: ตรวจสอบความพร้อมของเครื่อง

```bash
cd ~/AI-Camp
./scripts/check_setup.sh
```

ทุกบรรทัดควรเป็น **สีเขียว**

ยกเว้นบรรทัดเดียวที่ยังเป็นสีแดงได้ คือ `config.h says ..., this machine is ...`
เพราะยังไม่ได้ตั้งค่าหุ่นของเครื่องนี้ ซึ่งจะตั้งในบทที่ 4

> ค่าเฉพาะเครื่อง (เลขเครื่อง, WiFi, IP) ยังไม่ต้องตั้งตอนนี้
> เลขเครื่องจะตั้งในบทที่ 1 ส่วนค่าอื่นจะตั้งในบทที่ 4
