# 1. ใช้ Terminal เบื้องต้น

**Terminal** คือหน้าต่างที่เราพิมพ์คำสั่งให้คอมพิวเตอร์ทำงาน
งานเกือบทั้งหมดใน ROS 2 ทำผ่าน terminal

วิธีเปิด terminal:

- กด **Ctrl+Alt+T**
- หรือใน VS Code กด **Ctrl+`** (ปุ่ม ` อยู่เหนือปุ่ม Tab)

## คำสั่งพื้นฐาน 6 คำสั่ง

| คำสั่ง | ทำอะไร |
|---|---|
| `pwd` | บอกว่าตอนนี้อยู่โฟลเดอร์ไหน |
| `ls` | ดูว่าในโฟลเดอร์มีอะไรบ้าง |
| `cd ชื่อโฟลเดอร์` | เข้าไปในโฟลเดอร์ |
| `cd ..` | ถอยออกมาหนึ่งชั้น |
| `cat ชื่อไฟล์` | แสดงข้อความในไฟล์ |
| `clear` | ล้างหน้าจอ |

ลองพิมพ์ทีละบรรทัด (หรือกดปุ่มคัดลอก แล้ววางทั้งก้อนก็ได้):

```bash
cd ~/AI-Camp
pwd
ls
cd docs
ls
cat 01-terminal.md
cd ..
```

ผลลัพธ์ที่ควรเห็น (บางส่วน):

```text
/home/ชื่อคุณ/AI-Camp
docs  firmware  ros2_ws  scripts
```

## ปุ่มลัด 3 ปุ่มที่ควรจำ

- **Tab** เติมชื่อไฟล์หรือโฟลเดอร์ให้ครบ
  เช่น พิมพ์ `cd doc` แล้วกด Tab จะกลายเป็น `cd docs/` ช่วยไม่ให้พิมพ์ผิด
- **ลูกศรขึ้น** เรียกคำสั่งที่เคยพิมพ์กลับมา ไม่ต้องพิมพ์ใหม่
- **Ctrl+C** หยุดโปรแกรมที่กำลังทำงาน
  โปรแกรม ROS 2 ส่วนใหญ่จะทำงานไปเรื่อย ๆ จนกว่าเราจะกด Ctrl+C
  ถ้ากดแล้วยังไม่หยุด ให้ปิดแท็บ terminal นั้นทิ้ง แล้วเปิดใหม่

## เปิดหลาย terminal พร้อมกัน

ใน ROS 2 เราใช้ **1 terminal ต่อ 1 โปรแกรม** และมักรันหลายโปรแกรมพร้อมกัน

ใน VS Code กดปุ่ม **+** ที่แผง terminal เพื่อเปิดอันใหม่ แล้วคลิกสลับไปมาได้
บทที่ 5 จะเปิดพร้อมกัน 3-4 อัน เป็นเรื่องปกติ

## `source` คืออะไร

terminal ที่เพิ่งเปิดยังไม่รู้จักคำสั่ง `ros2`
ถ้าพิมพ์ไปเลยจะขึ้นว่า `command not found`

เราต้องสั่ง `source` ก่อน เพื่อบอก terminal ว่าโปรแกรม ROS 2 อยู่ที่ไหน:

```bash
source /opt/ros/jazzy/setup.bash
source ~/AI-Camp/ros2_ws/install/setup.bash
```

(ถ้าเครื่องเป็น Ubuntu 22.04 ให้เปลี่ยน `jazzy` เป็น `humble`)

### ให้ terminal ทำ `source` ให้เองทุกครั้ง

ถ้าไม่อยากพิมพ์สองบรรทัดนั้นทุกครั้งที่เปิด terminal
ให้เพิ่มไว้ในไฟล์ `~/.bashrc` (ไฟล์ที่ terminal อ่านทุกครั้งที่เปิด):

```bash
grep -qxF "source /opt/ros/jazzy/setup.bash" ~/.bashrc || echo "source /opt/ros/jazzy/setup.bash" >> ~/.bashrc
grep -qxF "source ~/AI-Camp/ros2_ws/install/setup.bash" ~/.bashrc || echo "source ~/AI-Camp/ros2_ws/install/setup.bash" >> ~/.bashrc
```

คำสั่งนี้เพิ่มบรรทัดเฉพาะตอนที่ยังไม่มี จึงรันซ้ำได้โดยไม่เกิดบรรทัดซ้ำ
(Ubuntu 22.04 ให้เปลี่ยน `jazzy` เป็น `humble` ในบรรทัดแรก)

> ระวัง: `>>` แปลว่า **ต่อท้าย** ไฟล์ ส่วน `>` แปลว่า **เขียนทับทั้งไฟล์** อย่าพิมพ์สลับกัน

### ข้อยกเว้น: ตอน build firmware

ตอน build โปรแกรมลงหุ่น ROS ที่ source ไว้จะตีกับเครื่องมือของ firmware
ไม่ต้องกังวล สคริปต์ `scripts/build_firmware.sh` จัดการให้แล้ว
แค่จำไว้ว่า **build firmware ด้วยสคริปต์นี้ทุกครั้ง**

## ตรวจว่าใช้งานได้

**ปิด terminal เดิม แล้วเปิดอันใหม่** จากนั้นพิมพ์:

```bash
ros2 --help
```

- ถ้าขึ้นหน้าคำอธิบายของ `ros2` แสดงว่าพร้อมแล้ว
- ถ้าขึ้น `command not found` แสดงว่าขั้น `source` ยังไม่ทำงาน ดู [troubleshooting.md](troubleshooting.md)
