# 1. ใช้ Terminal เบื้องต้น

**Terminal** คือหน้าต่างสำหรับพิมพ์คำสั่งให้คอมพิวเตอร์ทำงาน
งานเกือบทั้งหมดใน ROS 2 ทำผ่าน terminal

ค่ายนี้ใช้โปรแกรม **Terminator** ซึ่งแบ่งหน้าต่างเดียวออกเป็นหลาย terminal ได้


## คำสั่งพื้นฐาน 6 คำสั่ง

| คำสั่ง | ทำอะไร |
|---|---|
| `pwd` | บอกว่าตอนนี้อยู่โฟลเดอร์ไหน |
| `ls` | ดูว่าในโฟลเดอร์มีอะไรบ้าง |
| `cd ชื่อโฟลเดอร์` | เข้าไปในโฟลเดอร์ |
| `cd ..` | ถอยออกมาหนึ่งชั้น |
| `cat ชื่อไฟล์` | แสดงข้อความในไฟล์ |
| `clear` | ล้างหน้าจอ |

ลองพิมพ์ทีละบรรทัด (หรือกดปุ่มคัดลอกแล้ววางทั้งชุดก็ได้):

```bash
cd ~/AI-Camp
pwd
ls
cd docs
ls
cat 01-terminal.md
cd ..
```

ผลลัพธ์ที่ควรเห็น (บางส่วน):

```text
/home/ชื่อเครื่อง/AI-Camp
docs  firmware  ros2_ws  scripts
```

## ปุ่มลัด 3 ปุ่มที่ควรจำ

- **Tab** เติมชื่อไฟล์หรือโฟลเดอร์ให้ครบ
  เช่น พิมพ์ `cd doc` แล้วกด Tab จะเติมเป็น `cd docs/` ให้เอง ช่วยลดการพิมพ์ผิด
- **ลูกศรขึ้น** เรียกคำสั่งที่เคยพิมพ์กลับมา ไม่ต้องพิมพ์ใหม่
- **Ctrl+C** หยุดโปรแกรมที่กำลังทำงาน
  โปรแกรม ROS 2 ส่วนใหญ่จะทำงานไปเรื่อย ๆ จนกว่าเราจะกด Ctrl+C
  ถ้ากดแล้วยังไม่หยุด ให้ปิดช่อง terminal นั้น (**Ctrl+Shift+W**) แล้วเปิดช่องใหม่

## เปิดหลาย terminal พร้อมกัน

ใน ROS 2 เราใช้ **1 terminal ต่อ 1 โปรแกรม** และมักรันหลายโปรแกรมพร้อมกัน
Terminator แบ่งหน้าต่างออกเป็นหลายช่อง แต่ละช่องเป็น terminal แยกกัน:

| ปุ่มลัด | ทำอะไร |
|---|---|
| **Ctrl+Shift+E** | แบ่งช่องปัจจุบันเป็นซ้าย-ขวา |
| **Ctrl+Shift+O** | แบ่งช่องปัจจุบันเป็นบน-ล่าง |
| **Ctrl+Shift+T** | เปิดแท็บใหม่ |
| **คลิกเลือกช่อง แล้วกด Ctrl+Shift+D** | ปิดช่องที่เลือก |
| **Ctrl+Shift+L** | เคลียร์คำสั่งบนหน้าจอ |
| **Ctrl + เลื่อน scroll เมาส์** | ขยาย / ย่อขนาดตัวอักษร |

หรือคลิกขวาในช่องแล้วเลือก **Split Horizontally** / **Split Vertically**

ตัวอย่าง: แบ่งเป็น 4 ช่องสำหรับบทที่ 4

```text
┌───────────────────┬───────────────────┐
│ 1. agent          │ 2. key_teleop     │
├───────────────────┼───────────────────┤
│ 3. ros2 node list │ 4. topic echo     │
└───────────────────┴───────────────────┘
```

กด **Ctrl+Shift+E** หนึ่งครั้ง แล้วกด **Ctrl+Shift+O** ในแต่ละฝั่ง
ในบทที่ 4 จะต้องเปิดพร้อมกัน 3-4 ช่อง ซึ่งเป็นเรื่องปกติ

## `source` คืออะไร

terminal ที่เพิ่งเปิดยังไม่รู้จักคำสั่ง `ros2`
ถ้าพิมพ์ทันทีจะขึ้นข้อความ `command not found`

เราต้องสั่ง `source` ก่อน เพื่อบอก terminal ว่าโปรแกรม ROS 2 อยู่ที่ไหน:

```bash
source ~/AI-Camp/ros2_ws/install/setup.bash
```

### ตั้งค่าใน `~/.bashrc` ครั้งเดียว

`~/.bashrc` คือไฟล์ที่ terminal อ่านทุกครั้งที่เปิด
ใส่การตั้งค่าไว้ในไฟล์นี้ครั้งเดียว terminal ทุกอันที่เปิดหลังจากนี้จะพร้อมใช้งานทันที

1. เปิดไฟล์ด้วยโปรแกรมแก้ไขข้อความ:

   ```bash
   gedit ~/.bashrc
   ```

2. เลื่อนลงไป **ล่างสุดของไฟล์** แล้วพิมพ์เพิ่ม 3 บรรทัดนี้
   โดยแทน `<เลขเครื่อง>` ด้วย **หมายเลขเครื่องคอมพิวเตอร์ที่ใช้อยู่** เช่น เครื่องที่ 7 พิมพ์ `export ROS_DOMAIN_ID=7`

   ```bash
   source /opt/ros/jazzy/setup.bash
   source ~/AI-Camp/ros2_ws/install/setup.bash
   export ROS_DOMAIN_ID=<เลขเครื่อง>
   ```

3. กด **Ctrl+S** เพื่อบันทึก แล้วปิด gedit

| บรรทัด | ทำอะไร |
|---|---|
| `source` 2 บรรทัด | ให้ terminal รู้จักคำสั่ง ROS 2 และโปรแกรมของค่าย |
| `export ROS_DOMAIN_ID` | เลขเครื่อง ใช้แยก ROS 2 ของแต่ละเครื่องไม่ให้ปนกัน (อธิบายในบทที่ 2) |

> ถ้าในไฟล์มีบรรทัด `export ROS_DOMAIN_ID=...` อยู่แล้ว ให้แก้เลขในบรรทัดเดิม ไม่ต้องเพิ่มบรรทัดใหม่
> ถ้ามีสองบรรทัด ระบบจะใช้บรรทัดล่างสุด

### ข้อยกเว้น: ตอน build firmware

ตอน build โปรแกรมลงหุ่น ROS ที่ source ไว้จะชนกับเครื่องมือ build ของ firmware
ไม่ต้องกังวล สคริปต์ `scripts/build_firmware.sh` จัดการให้แล้ว
แค่จำไว้ว่า **build firmware ด้วยสคริปต์นี้ทุกครั้ง**

## ตรวจสอบว่าใช้งานได้

**ปิด Terminator แล้วเปิดใหม่** จากนั้นพิมพ์:

```bash
ros2 --help
```

- ถ้าขึ้นหน้าคำอธิบายของ `ros2` แสดงว่าพร้อมแล้ว
- ถ้าขึ้น `command not found` แสดงว่าการ `source` ยังไม่ได้ผล ดู [troubleshooting.md](troubleshooting.md)

จากนั้นเช็กเลขเครื่อง:

```bash
echo $ROS_DOMAIN_ID
```

ควรแสดงหมายเลขเครื่องที่ใช้อยู่ เช่น เครื่องที่ 7 จะแสดง `7`
