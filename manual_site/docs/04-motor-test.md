### แนวคิด: differential drive

ฟังก์ชัน `drive(lin, ang)` ได้รับคำสั่ง 2 ค่า:

| ค่า | ความหมาย |
|---|---|
| `lin` | เดินหน้าเร็วแค่ไหน (m/s) ค่าลบ = ถอยหลัง |
| `ang` | หมุนตัวเร็วแค่ไหน (rad/s) ค่าบวก = เลี้ยวซ้าย |

แต่หุ่นมีมอเตอร์ 2 ตัว งานของเราคือแปลงสองค่านี้เป็น
"ล้อซ้ายเร็วเท่าไร" และ "ล้อขวาเร็วเท่าไร"

```text
  เดินตรง:  ล้อซ้าย = ล้อขวา        เลี้ยวซ้าย:  ล้อขวาเร็วกว่าล้อซ้าย

     ซ้าย ▲▲▲   ▲▲▲ ขวา                ซ้าย ▲     ▲▲▲ ขวา
```

สิ่งที่รู้แล้ว:

- **เดินตรง** (`ang` = 0): ล้อทั้งสองหมุนเร็วเท่ากับ `lin`
- **เลี้ยว**: ล้อข้างหนึ่งเร็วขึ้น อีกข้างช้าลง ยิ่ง `ang` มาก สองล้อยิ่งต่างกันมาก
- ระยะห่างระหว่างสองล้อคือ `WHEEL_BASE` = 0.15 เมตร (ตั้งไว้ในโค้ดแล้ว ไม่ต้องวัด)

วิธีคำนวณว่าแต่ละล้อต้องเร็วขึ้นหรือช้าลงเท่าไร จะเรียนในห้อง

### เช็กคำตอบ

ลองแทนค่าในสูตรของคุณ ต้องได้ตามตารางนี้ (มีใน comment ของโค้ดด้วย):

| lin | ang | ล้อซ้าย | ล้อขวา | ความหมาย |
|---|---|---|---|---|
| 0.1 | 0 | 0.10 | 0.10 | เดินตรง |
| 0 | 2 | -0.15 | 0.15 | หมุนซ้ายอยู่กับที่ |

> **ทำไมไม่ต้องใช้ขนาดล้อ?**
> หุ่นตัวนี้ไม่มีตัววัดความเร็วล้อ (encoder) ตัวเลข "m/s" จึงเป็นแค่ระดับแรงของมอเตอร์
> (`MAX_LIN` = 0.30 คือแรงสุด) ค่าประมาณก็ใช้ได้

ถ้ายังไม่ได้เขียนส่วนนี้ โปรแกรมทดสอบจะรันจนจบ แต่ล้อจะไม่หมุนเลย

## Upload

พิมพ์ใน terminal:

```bash
cd ~/AI-Camp
./scripts/build_firmware.sh motortest upload
```

เปิดดูข้อความจากบอร์ด (กด Ctrl+C เพื่อออก):

```bash
./scripts/build_firmware.sh motortest monitor
```

ผลลัพธ์ที่ควรเห็น:

```text
motor test -- put the robot on a book, wheels in the air
[1/9] LEFT wheel forward   (right should be still)
[2/9] LEFT wheel backward
[3/9] RIGHT wheel forward  (left should be still)
...
```

> ถ้า upload ไม่สำเร็จ ดู [troubleshooting.md](troubleshooting.md#the-board-wont-upload)

## ถ้าไม่เป็นไปตามตาราง

**ล้อหมุนกลับทิศ**
เลือกทำอย่างใดอย่างหนึ่ง แล้ว upload ใหม่:

- สลับสายสองเส้นของมอเตอร์ตัวนั้นที่ driver
- หรือสลับเลขขาใน [motor.h](../firmware/include/motor.h)
  (`L_IN1` กับ `L_IN2` สำหรับล้อซ้าย, `R_IN1` กับ `R_IN2` สำหรับล้อขวา)

ถ้ากลับทิศทั้งสองล้อ ให้แก้ทั้งสองคู่

**ล้อซ้ายกับขวาสลับกัน**
มอเตอร์ซ้ายกับขวาต่อสลับกันที่ driver ให้สลับสายสองคู่นั้น

**ล้อไม่หมุนเลย แต่ข้อความบนหน้าจอขึ้นปกติ**
ESP32 ใช้ไฟจาก USB ได้ แต่มอเตอร์ต้องใช้ไฟจากแบตเตอรี่ ให้เช็ก:

- ต่อแบตเตอรี่และเปิดสวิตช์แล้ว
- **jumper ที่ ENA/ENB ยังเสียบอยู่**

**มอเตอร์มีเสียงหึ่ง ๆ แต่ไม่หมุน**
แรงไม่พอ เปิด [motor.h](../firmware/include/motor.h) แล้วเพิ่มค่า `MIN_DUTY` ทีละนิดจนมอเตอร์หมุน

**บอร์ดรีสตาร์ทเองซ้ำ ๆ**
มอเตอร์ดึงไฟมากจนไฟตก ให้ใช้แบตเตอรี่แยกสำหรับมอเตอร์
และเช็กว่าต่อสาย GND ร่วมกันแล้ว ([03-hardware.md](03-hardware.md))

**หมุนแค่ล้อเดียวตลอดการทดสอบ**
ส่วนใหญ่เลขขาใน [motor.h](../firmware/include/motor.h) ไม่ตรงกับสายจริง
เทียบทีละขากับตารางใน [03-hardware.md](03-hardware.md) แล้วเช็กสาย IN ของล้อข้างนั้นที่ driver
