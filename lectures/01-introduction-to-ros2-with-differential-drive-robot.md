## 1. System Overview

Terminal ใช้เปิดและตรวจสอบโปรแกรม ส่วน ROS 2 เชื่อมข้อมูลระหว่างโปรแกรม โปรแกรมควบคุมแปลงคำสั่งจากผู้ใช้เป็นความเร็ว แล้วหุ่นยนต์แปลงความเร็วนั้นเป็นการหมุนของล้อ

```text
Keyboard / Phone
        │
        ▼
Control program ── ROS 2 messages ──→ Robot interface
                                          │
                                          ▼
                                   Left / Right motors

Terminal: run programs and inspect data
```

## 2. Hardware Overview

| อุปกรณ์ | หน้าที่ |
|---|---|
| ESP32 | รับคำสั่งและสร้างสัญญาณควบคุม |
| Motor driver | ใช้สัญญาณจาก ESP32 ควบคุมกำลังไฟที่ส่งให้มอเตอร์ |
| Battery | จ่ายกำลังไฟให้มอเตอร์ผ่าน Motor driver |
| Motors | ขับล้อซ้ายและล้อขวา |

```text
ESP32 ── Control signals ──→ Motor driver ── Power ──→ Motors
                                  ▲
                                  │ Power
                               Battery

ESP32 GND ───────────────── Motor driver GND
```

ESP32 ส่งสัญญาณควบคุม ส่วนแบตเตอรี่จ่ายกำลังให้มอเตอร์ผ่าน Motor driver โดย ESP32 และ Motor driver ต้องเชื่อม GND ร่วมกัน ไฟสถานะบน ESP32 ไม่ได้แสดงว่ามอเตอร์ได้รับกำลังไฟแล้ว

## 3. Basic Robot Control

โปรแกรมบน Arduino หรือ ESP32 ส่งสัญญาณให้ Motor driver ขับมอเตอร์ เช่น เดินหน้าสองวินาทีแล้วหยุด

```text
Program → Microcontroller → Motor driver → Motors → Motion
```

Arduino ใช้ `setup()` เตรียมอุปกรณ์ และ `loop()` ทำงานซ้ำ ตัวอย่างการเคลื่อนที่ตามเวลามีลำดับดังนี้:

```text
Start → Prepare motors
             │
             ▼
      Forward for 2 seconds
             │
             ▼
      Stop for 2 seconds
             │
             └──── Repeat
```

หากเพิ่ม Sensor โปรแกรมจะใช้ข้อมูลที่วัดได้เลือกการทำงาน เช่น หยุดเมื่อพบสิ่งกีดขวางใกล้เกินไป

```text
             ┌──────────────┐     ┌────────────────┐     ┌──────────────┐
             │  Controller  │     │  Motor driver  │     │    Robot     │
        ┌───→│ Make decision│────→│    & Motors    │────→│    Motion    │───┐
        │    └──────────────┘     └────────────────┘     └──────────────┘   │
        │                                                                  │
        │                         ┌────────────────┐                       │
        └─────────────────────────│     Sensor     │←──────────────────────┘
                  Feedback        │  Measure data  │
                                  └────────────────┘
```

## 4. Robot Communication

หากสั่งงานจากคอมพิวเตอร์ ต้องมีช่องทางส่งคำสั่งไปยังหุ่นยนต์ เช่น กดปุ่มลูกศรเพื่อเลือกทิศทาง

```text
                    ┌─────┐
                    │  ↑  │
                    └─────┘
             ┌─────┐┌─────┐┌─────┐
             │  ←  ││  ↓  ││  →  │
             └─────┘└─────┘└─────┘
```

| ปุ่ม | คำสั่งในตัวอย่าง |
|---|---|
| ↑ | เดินหน้า |
| ↓ | ถอยหลัง |
| ← | เลี้ยวซ้าย |
| → | เลี้ยวขวา |

```text
Keyboard → Computer program → Connection → Robot program → Motors
```

การเชื่อมต่อมีหลายทาง ผู้ส่งและผู้รับต้องใช้รูปแบบข้อมูลและความหมายของคำสั่งตรงกัน

```text
                          Connection / Protocol
                         ┌─────────────────────┐
                    ┌───→│ USB Serial          │───┐
┌──────────────┐    │    ├─────────────────────┤   │    ┌──────────────┐
│ Command      │────┼───→│ Bluetooth           │───┼───→│ Robot        │
│ program      │    │    ├─────────────────────┤   │    │ program      │
└──────────────┘    └───→│ WiFi + TCP / UDP    │───┘    └──────────────┘
                         └─────────────────────┘
```

WiFi ใช้เชื่อมเครือข่าย ส่วน TCP และ UDP ใช้รับส่งข้อมูลบนเครือข่าย จึงทำงานร่วมกันคนละระดับ

## 5. Communication with Multiple Devices

โปรแกรมบน Microcontroller ต้องอ่านคำสั่งผู้ใช้และสั่ง Motor driver ซึ่งแต่ละอุปกรณ์มีวิธีรับส่งข้อมูลต่างกัน เมื่อมีหลายอุปกรณ์ รายละเอียดที่โปรแกรมต้องจัดการก็เพิ่มขึ้น

```text
Joystick → Read input → Select velocity → Motor driver → Motors
```

ROS 2 จัดการการสื่อสารระหว่างโปรแกรม ส่วน Driver รับผิดชอบการอ่านและเขียนอุปกรณ์ ข้อมูล Sensor จึงส่งต่อให้โปรแกรมอื่นใช้งานได้

## 6. ROS 2 Overview

**ROS 2** เป็นชุดซอฟต์แวร์สำหรับสร้างระบบหุ่นยนต์ที่มีหลายโปรแกรมทำงานร่วมกัน มีทั้ง Library สำหรับเขียนโปรแกรม ระบบรับส่งข้อมูล และเครื่องมือสำหรับตรวจสอบการทำงาน

ตัวอย่างเช่น การควบคุมหุ่นยนต์ด้วย Keyboard แบ่งเป็นสองหน้าที่: โปรแกรมบนคอมพิวเตอร์อ่านปุ่มและสร้างคำสั่งความเร็ว ส่วนโปรแกรมบนหุ่นยนต์รับคำสั่งแล้วควบคุมล้อ ROS 2 ช่วยให้สองส่วนนี้แลกเปลี่ยนข้อมูลกันได้

```text
Computer                                  Robot
┌──────────────────┐                      ┌──────────────────┐
│ Read keyboard    │   Velocity message   │ Receive command  │
│ Select velocity  │ ───────────────────→ │ Control wheels   │
└──────────────────┘                      └──────────────────┘
                  ROS 2 communication
```

โปรแกรมทั้งสองใช้รูปแบบข้อมูลที่กำหนดร่วมกัน ฝั่ง Keyboard จึงไม่ต้องรู้รายละเอียดการต่อมอเตอร์ และฝั่งควบคุมล้อไม่ต้องรู้ว่าคำสั่งมาจากปุ่มใด หากเปลี่ยนเป็น Joystick ก็สามารถส่งคำสั่งความเร็วรูปแบบเดิมได้

| ส่วนที่ ROS 2 จัดเตรียม | ประโยชน์ |
|---|---|
| Library | ใช้พัฒนาโปรแกรมแต่ละส่วนของหุ่นยนต์ |
| ระบบสื่อสาร | ส่งคำสั่งและข้อมูลระหว่างโปรแกรม |
| เครื่องมือตรวจสอบ | ดูว่าโปรแกรมใดทำงานและกำลังส่งข้อมูลอะไร |

**ROS** ย่อมาจาก **Robot Operating System** แต่ ROS 2 ทำงานบน OS เช่น Ubuntu ส่วนพฤติกรรมของหุ่นยนต์ เช่น การเลือกความเร็วหรือการหยุด ยังต้องกำหนดในโปรแกรมควบคุม

## 7. Ubuntu 24.04 and ROS 2 Jazzy

**Ubuntu** เป็น Operating System หรือ OS ที่จัดการคอมพิวเตอร์ คล้ายบทบาทของ Windows ส่วน ROS 2 เป็นซอฟต์แวร์ที่ทำงานบน OS

| ซอฟต์แวร์ที่ใช้ในค่าย | บทบาท |
|---|---|
| Ubuntu 24.04 LTS | เป็นระบบพื้นฐานให้โปรแกรมทำงาน |
| ROS 2 Jazzy | ให้เครื่องมือและการสื่อสารสำหรับซอฟต์แวร์หุ่นยนต์ |

```text
Robot applications
        ↕
ROS 2 Jazzy
        ↕
Ubuntu 24.04
        ↕
Computer hardware
```

Ubuntu 24.04 และ ROS 2 Jazzy รองรับกัน การใช้เวอร์ชันเดียวกันทำให้ทุกเครื่องใช้คำสั่งและเครื่องมือชุดเดียวกัน

## 8. Differential Drive

หุ่นยนต์ Differential Drive ควบคุมล้อซ้ายและล้อขวาแยกกัน การเปลี่ยนความเร็วล้อทำให้หุ่นยนต์เลี้ยวได้

| ล้อซ้าย | ล้อขวา | การเคลื่อนที่ |
|---|---|---|
| เดินหน้า | เดินหน้าความเร็วเท่ากัน | เดินหน้าตรง |
| เดินหน้าช้ากว่า | เดินหน้าเร็วกว่า | เลี้ยวโค้งซ้าย |
| เดินหน้าเร็วกว่า | เดินหน้าช้ากว่า | เลี้ยวโค้งขวา |
| ถอยหลัง | เดินหน้าความเร็วเท่ากัน | หมุนซ้ายอยู่กับที่ |
| หยุด | หยุด | หยุด |

โปรแกรมสั่งความเร็วเดินหน้าและความเร็วในการหมุน แล้วส่วนควบคุมล้อแปลงเป็นคำสั่งมอเตอร์แต่ละข้าง

## 9. Robot System Overview

คอมพิวเตอร์ใช้ ROS 2 ส่งคำสั่ง ส่วน ESP32 ใช้ micro-ROS รับคำสั่งและควบคุมมอเตอร์ โดยมี micro-ROS agent เชื่อมการสื่อสาร

```text
Computer                                       Robot
┌─────────────────┐                       ┌─────────────────┐
│ Control program │                       │ ESP32           │
│ ROS 2           │                       │ micro-ROS       │
│ micro-ROS agent │ ←───── WiFi ─────────→ │ Motor control   │
└─────────────────┘                       └────────┬────────┘
                                                   ▼
                                             Motor driver
                                                   ▼
                                             Left / Right
                                                 motors
```

ส่วนควบคุมมอเตอร์จึงรับคำสั่งจาก Keyboard, MQTT หรือโปรแกรมอื่นได้ หากใช้รูปแบบข้อมูลเดียวกัน

### Teleoperation Data Flow

```text
Keyboard ──→ key_teleop ────────────────────┐
                                           ▼
                                     /cmd_vel → ESP32 → Motors
                                           ▲
Phone → MQTT broker → mqtt_teleop ──────────┘
```

Keyboard และ MQTT เป็นแหล่งคำสั่งคนละทาง แต่ส่ง Twist ให้หุ่นยนต์ผ่าน `/cmd_vel` เหมือนกัน ขณะทดสอบใช้ผู้ควบคุมเพียงตัวเดียว
