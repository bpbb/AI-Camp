# Lecture 4: Robot Interface and Differential Drive

**Camp:** NextGen AI Camp 2026

## Learning Objectives

- อธิบายความสัมพันธ์ระหว่างความเร็วตัวหุ่นยนต์กับความเร็วล้อ
- อ่านค่า `linear.x` และ `angular.z` ในคำสั่ง `/cmd_vel`
- เชื่อมคำสั่ง ROS 2 กับการเคลื่อนที่ของหุ่นยนต์จริง

## 1. Differential Drive Structure

หุ่นยนต์ Differential Drive ใช้มอเตอร์แยกสำหรับล้อซ้ายและล้อขวา ส่วน Caster ช่วยพยุงตัว การเลี้ยวเกิดจากความเร็วล้อสองข้างต่างกัน

```text
                    Forward (+x)
                         ↑
                 ┌───────────────┐
Left wheel  O─────┤     Robot     ├─────O  Right wheel
                 └───────┬───────┘
                         o
                       Caster
```

| ล้อซ้าย | ล้อขวา | ผลที่ได้ |
|---|---|---|
| เดินหน้า | เดินหน้าความเร็วเท่ากัน | เดินหน้าตรง |
| ถอยหลัง | ถอยหลังความเร็วเท่ากัน | ถอยหลังตรง |
| เดินหน้าช้ากว่า | เดินหน้าเร็วกว่า | เลี้ยวโค้งซ้าย |
| เดินหน้าเร็วกว่า | เดินหน้าช้ากว่า | เลี้ยวโค้งขวา |
| ถอยหลัง | เดินหน้าความเร็วเท่ากัน | หมุนซ้ายอยู่กับที่ |
| เดินหน้า | ถอยหลังความเร็วเท่ากัน | หมุนขวาอยู่กับที่ |

## 2. Linear and Angular Velocity

คำสั่งการเคลื่อนที่ระบุความเร็วของตัวหุ่นยนต์ก่อน แล้วโปรแกรมจึงคำนวณความเร็วล้อแต่ละข้าง

| ค่า | ความหมาย | เครื่องหมาย |
|---|---|---|
| Linear velocity `v` | ความเร็วเดินหน้า หน่วย m/s | บวกคือเดินหน้า ลบคือถอยหลัง |
| Angular velocity `ω` | ความเร็วในการหมุน หน่วย rad/s | บวกคือหมุนซ้าย ลบคือหมุนขวา เมื่อมองจากด้านบน |

```text
                  Robot velocity
                v             ω
                │             │
                └──────┬──────┘
                       ▼
             Differential drive
                       │
               ┌───────┴───────┐
               ▼               ▼
           Left wheel      Right wheel
```

เดินหน้าตรงใช้ `v` อย่างเดียว หมุนอยู่กับที่ใช้ `ω` อย่างเดียว ส่วนการเลี้ยวโค้งใช้ทั้งสองค่าร่วมกัน

## 3. Velocity Messages

Topic `/cmd_vel` รับคำสั่งชนิด `geometry_msgs/msg/Twist` โดยหุ่นยนต์นี้ใช้สอง Field:

| Field | ค่าที่แทน |
|---|---|
| `linear.x` | `v` ความเร็วเดินหน้า |
| `angular.z` | `ω` ความเร็วในการหมุน |

ตัวอย่างข้อมูลเดินหน้าพร้อมเลี้ยวซ้าย:

```yaml
linear:
  x: 0.1
angular:
  z: 0.5
```

Field อื่นของ Twist เป็นศูนย์ในตัวอย่างนี้ โดยโปรแกรมบน ESP32 ใช้ `linear.x` และ `angular.z` ควบคุมการเคลื่อนที่

ตัวอย่างคำสั่งที่สร้าง Message นี้:

```bash
ros2 topic pub -r 10 /cmd_vel geometry_msgs/msg/Twist \
  '{linear: {x: 0.1}, angular: {z: 0.5}}'
```

`pub` ทำหน้าที่ส่ง ส่วน `-r 10` ส่งซ้ำสิบครั้งต่อวินาที ค่าใน Message ระบุความเร็วที่ต้องการ ไม่ใช่ความเร็วล้อที่วัดได้

## 4. Wheel Velocity Conversion

`/cmd_vel` ระบุความเร็วของ **ตัวหุ่นยนต์** ไม่ใช่ความเร็วของล้อแต่ละข้าง โปรแกรมจึงต้องแปลงคำสั่งนี้เป็นความเร็วล้อซ้ายและล้อขวา

### Variables and Units

| ตัวแปร | ความหมาย | ค่าที่ใช้ในตัวอย่าง |
|---|---|---|
| `v` | ความเร็วเดินหน้าจาก `linear.x` | `0.10 m/s` |
| `ω` | ความเร็วในการหมุนจาก `angular.z` | `0.50 rad/s` |
| `b` | ระยะห่างระหว่างกึ่งกลางล้อซ้ายและล้อขวา | `0.15 m` หรือ `15 cm` |
| `vL`, `vR` | ความเร็วเชิงเส้นของล้อซ้ายและล้อขวา | ค่าที่ต้องคำนวณ |

### Forward Motion and Turning

การเดินหน้าทำให้ล้อทั้งสองมีความเร็วพื้นฐานเท่ากับ `v` ส่วนการเลี้ยวเพิ่มความเร็วล้อข้างหนึ่งและลดอีกข้างด้วยขนาดเท่ากัน

ล้อแต่ละข้างอยู่ห่างจากกึ่งกลางหุ่นยนต์ `b / 2` ความเร็วส่วนที่เกิดจากการหมุนจึงเท่ากับ `ω × b / 2`

```text
                  Robot centre
                       │
 Left wheel            │            Right wheel
     O─────────────────┼─────────────────O
     │←──── b / 2 ────→│←──── b / 2 ────→│

 Turning adjustment: Δv = ω × b / 2

 Left:  vL = v − Δv           Right: vR = v + Δv
```

เมื่อ `ω` เป็นบวก หุ่นยนต์ต้องเลี้ยวซ้าย จึงลดความเร็วล้อซ้ายและเพิ่มความเร็วล้อขวา หาก `ω` เป็นลบ ผลจะกลับกัน

### Forward Left Turn Calculation

ตัวอย่างคำสั่ง `/cmd_vel` มีค่า:

```text
linear.x  = 0.10 m/s
angular.z = 0.50 rad/s
```

แทนค่าระยะห่างล้อ `b = 0.15 m` แล้วคำนวณตามลำดับ:

```text
1. Half the wheel separation
   b / 2 = 0.15 / 2 = 0.075 m

2. Turning adjustment
   Δv = ω × b / 2
      = 0.50 × 0.075
      = 0.0375 m/s

3. Left wheel velocity
   vL = v − Δv
      = 0.10 − 0.0375
      = 0.0625 m/s

4. Right wheel velocity
   vR = v + Δv
      = 0.10 + 0.0375
      = 0.1375 m/s
```

ล้อขวาเร็วกว่า จึงเกิดการเลี้ยวโค้งซ้าย ค่า `0.0625` และ `0.1375 m/s` เป็นความเร็วล้อที่คำนวณได้ ส่วนค่าที่ส่งใน `/cmd_vel` ยังคงเป็น `linear.x = 0.1` และ `angular.z = 0.5`

### Straight Motion and In-Place Rotation

ใช้ `b = 0.15 m` เช่นเดิม:

| การเคลื่อนที่ | `linear.x = v` | `angular.z = ω` | `Δv = ω × 0.075` | `vL = v − Δv` | `vR = v + Δv` |
|---|---|---|---|---|---|
| เดินหน้าตรง | `0.10` | `0` | `0` | `0.10` | `0.10` |
| หมุนซ้ายอยู่กับที่ | `0` | `1.0` | `0.075` | `-0.075` | `0.075` |
| หมุนขวาอยู่กับที่ | `0` | `-1.0` | `-0.075` | `0.075` | `-0.075` |

ค่าติดลบของล้อหมายถึงหมุนถอยหลัง เมื่อความเร็วล้อมีขนาดเท่ากันแต่ทิศตรงข้าม หุ่นยนต์จะหมุนอยู่กับที่ในแบบจำลองอุดมคติ

### Inverse Velocity Conversion

หากกำหนดความเร็วล้อไว้ก่อน สามารถคำนวณค่าที่ต้องส่งใน `/cmd_vel` ย้อนกลับได้:

```text
linear.x  = v = (vR + vL) / 2
angular.z = ω = (vR − vL) / b
```

ตัวอย่างต้องการให้ล้อซ้ายเดินหน้า `0.05 m/s` และล้อขวาเดินหน้า `0.15 m/s` เมื่อ `b = 0.15 m`:

```text
v = (0.15 + 0.05) / 2 = 0.10 m/s
ω = (0.15 − 0.05) / 0.15 ≈ 0.67 rad/s
```

ค่าที่ส่งจึงเป็น `linear.x = 0.10` และ `angular.z ≈ 0.67` เพื่อให้หุ่นยนต์เลี้ยวซ้าย

การคำนวณนี้ใช้ความเร็วเชิงเส้นของล้อ หน่วย m/s ไม่ใช่ RPM และเป็นค่าตามแบบจำลองก่อนพิจารณาขีดจำกัดมอเตอร์หรือการลื่นไถล

## 5. Robot Command Processing

คำสั่งความเร็วผ่านสามขั้น: รับ Message คำนวณความเร็วล้อ และสร้างสัญญาณมอเตอร์

```text
Twist received
      │ linear.x, angular.z
      ▼
onCmdVel() ──→ drive(lin, ang) ──→ Left / Right velocity
      │                                  │
      ▼                                  ▼
Update lastCommand                 GPIO / PWM → Motors
```

การรับคำสั่งและการคำนวณล้อเป็นคนละหน้าที่ ส่วนรับ Message อ่านความเร็วและบันทึกเวลารับล่าสุด ส่วน `drive()` คำนวณความเร็วล้อตามสมการ

## 6. Keyboard Teleoperation

Keyboard node เก็บค่าความเร็วแล้วส่ง Twist ซ้ำที่ 10 Hz การกดปุ่มเปลี่ยนค่าที่เก็บไว้ ไม่ได้สั่งขามอเตอร์โดยตรง

```text
Key press → Update lin / ang → Create Twist → /cmd_vel → Robot
                 │
                 └── Keep current values between key presses
```

| ปุ่ม | ผลต่อคำสั่ง |
|---|---|
| `w` / `s` | เพิ่ม / ลดความเร็วเดินหน้า |
| `a` / `d` | เพิ่ม / ลดความเร็วหมุนซ้าย |
| Space | ตั้งความเร็วทั้งสองค่าเป็นศูนย์ |
| `q` | หยุดและออก |

การปล่อยปุ่มไม่เปลี่ยนค่าที่เก็บไว้ โปรแกรมจึงส่งความเร็วเดิมต่อ ส่วน Space เปลี่ยนค่าความเร็วเป็นศูนย์ การหยุดกดปุ่มจึงต่างจากการส่งคำสั่งหยุด

## 7. Motor Response and Command Timeout

ระบบนี้เป็น Open-loop คือสั่งมอเตอร์โดยไม่มีการวัดความเร็วล้อกลับมาตรวจสอบ ความเร็วจริงจึงเปลี่ยนตามพื้นผิว น้ำหนัก และแบตเตอรี่

```text
Commands arrive repeatedly → Continue requested motion
Commands stop arriving     → Timeout check → Stop motors
```

ค่า Timeout คือ `500 ms` จึงต้องส่งคำสั่งต่อเนื่อง เวลาหยุดจริงอาจมากกว่านี้ขณะรอการสื่อสาร หากมีผู้ส่งอื่นส่งคำสั่งอยู่ หุ่นยนต์ยังรับคำสั่งนั้นต่อ
