## Upload

ที่แถบสถานะด้านล่างของ VS Code ให้คลิกตัวเลือก env แล้วเลือก
**`env:motortest`** จากนั้นคลิกลูกศร **→** เพื่อ upload

หรือใช้คำสั่งใน terminal:

```bash
./scripts/build_firmware.sh motortest upload
./scripts/build_firmware.sh motortest monitor    # แสดง output ทาง serial
```

เปิด Serial Monitor (ไอคอนรูปปลั๊ก) ระบบจะแสดงข้อความระบุแต่ละขั้นตอน
ขณะทำงาน:

```
motor test -- put the robot on a book, wheels in the air
[1/9] LEFT wheel forward   (right should be still)
[2/9] LEFT wheel backward
[3/9] RIGHT wheel forward  (left should be still)
...
```

## การตรวจสอบทีละขั้นตอน

สังเกตการหมุนของล้อและตรวจสอบตามตารางต่อไปนี้:

| ขั้นตอน | ผลที่ถูกต้อง |
|---|---|
| 1 | ล้อซ้ายหมุนไปข้างหน้า ล้อขวาอยู่นิ่ง |
| 2 | ล้อซ้ายหมุนถอยหลัง |
| 3 | ล้อขวาหมุนไปข้างหน้า ล้อซ้ายอยู่นิ่ง |
| 4 | ล้อขวาหมุนถอยหลัง |
| 5 | ล้อทั้งสองหมุนไปข้างหน้าด้วยความเร็วเท่ากัน |
| 6 | ล้อทั้งสองหมุนถอยหลัง |
| 7 | หมุนตัวไปทางซ้าย (ล้อซ้ายถอยหลัง ล้อขวาเดินหน้า) |
| 8 | หมุนตัวไปทางขวา |
| 9 | ล้อทั้งหมดหยุด |

## การแก้ไขปัญหา

**ล้อหมุนผิดทิศทาง** ให้สลับสายสองเส้นของมอเตอร์ตัวนั้นที่ driver หรือ
สลับขา direction ทั้งสองขาใน
[motor.h](../firmware/include/motor.h) (`L_IN1`/`L_IN2` สำหรับล้อ
ซ้าย, `R_IN1`/`R_IN2` สำหรับล้อขวา) แล้ว upload ใหม่ สามารถใช้วิธีใด
วิธีหนึ่ง หากล้อหมุนกลับทิศ*ทั้งสองข้าง* ให้สลับทั้งสองคู่

**ล้อที่หมุนไม่ตรงกับข้างที่สั่ง** มอเตอร์ซ้ายและขวาต่อสลับกันที่
driver ให้สลับสายสองคู่ดังกล่าว

**ล้อไม่หมุน แต่ Serial Monitor แสดงผลปกติ** ESP32 สามารถทำงานด้วยไฟ
จาก USB ได้ แต่มอเตอร์ไม่ได้รับไฟ ให้ตรวจสอบว่าต่อแบตเตอรี่และเปิดสวิตช์แล้ว

**มอเตอร์มีเสียงแต่ไม่หมุน** แรงขับไม่เพียงพอที่จะเอาชนะแรงเสียดทาน
ให้เปิด [motor.h](../firmware/include/motor.h) แล้วเพิ่มค่า `MIN_DUTY`
ทีละน้อยจนกว่ามอเตอร์จะหมุน

**บอร์ดรีสตาร์ทซ้ำ ๆ** มอเตอร์ดึงกระแสเกินกว่าที่แหล่งจ่ายไฟจะจ่ายได้
ทำให้แรงดันตก ให้ใช้แบตเตอรี่แยกสำหรับมอเตอร์ และตรวจสอบว่าต่อ ground
ร่วมกันแล้ว ([03-hardware.md](03-hardware.md))

**ล้อหมุนเพียงข้างเดียวตลอดการทดสอบ** สาเหตุส่วนใหญ่คือหมายเลขขาใน
[motor.h](../firmware/include/motor.h) ไม่ตรงกับการต่อสายจริง
ให้เทียบทีละขากับตารางใน
[03-hardware.md](03-hardware.md) จากนั้นตรวจสอบสายสามเส้นของล้อข้างนั้น
ที่ driver และตรวจสอบว่า ENA/ENB เป็น HIGH (มี jumper หรือต่อกับ GPIO 14/32)

## การวัดขนาดหุ่นยนต์

เปิดไฟล์ [motor.h](../firmware/include/motor.h) แล้วกำหนดค่า:

```c
#define WHEEL_BASE 0.15f   // metres between the two wheels
```

วัดระยะจากกึ่งกลางหน้ายางของล้อหนึ่งถึงกึ่งกลางหน้ายางของอีกล้อหนึ่ง
หากค่านี้ไม่ถูกต้อง หุ่นยนต์จะยังเคลื่อนที่ได้ แต่เมื่อสั่งให้เลี้ยว 90 องศา
มุมที่เลี้ยวจริงจะไม่เท่ากับ 90 องศา

## เงื่อนไขก่อนดำเนินการบทถัดไป

ทั้งเก้าขั้นตอนต้องทำงานถูกต้องครบถ้วน เมื่อผ่านเงื่อนไขนี้แล้ว หาก
หุ่นยนต์ไม่เคลื่อนที่ในบทถัดไป สามารถตัดสาเหตุที่เกิดจากฮาร์ดแวร์ออกได้
