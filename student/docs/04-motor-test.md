## Upload

ที่แถบสถานะด้านล่างของ VS Code คลิกตัวสลับ env แล้ว
เลือก **`env:motortest`** จากนั้นกดลูกศร **→** เพื่อ upload

หรือจะใช้ terminal ก็ได้:

```bash
./scripts/build_firmware.sh motortest upload
./scripts/build_firmware.sh motortest monitor    # ดู output
```

เปิด Serial Monitor (ไอคอนรูปปลั๊ก) คุณควรเห็นหุ่นประกาศ
แต่ละขั้นตอนตอนที่มันทำ:

```
motor test -- put the robot on a book, wheels in the air
[1/9] LEFT wheel forward   (right should be still)
[2/9] LEFT wheel backward
[3/9] RIGHT wheel forward  (left should be still)
...
```

## เช็กทีละขั้นตอน

ดูล้อแล้วติ๊กตามนี้:

| ขั้นตอน | สิ่งที่ต้องเกิดขึ้น |
|---|---|
| 1 | ล้อซ้ายหมุนไปข้างหน้า ล้อขวาอยู่นิ่ง |
| 2 | ล้อซ้ายหมุนถอยหลัง |
| 3 | ล้อขวาหมุนไปข้างหน้า ล้อซ้ายอยู่นิ่ง |
| 4 | ล้อขวาหมุนถอยหลัง |
| 5 | หมุนไปข้างหน้าทั้งคู่ ความเร็วเท่ากัน |
| 6 | หมุนถอยหลังทั้งคู่ |
| 7 | หมุนตัวไปทางซ้าย (ซ้ายถอย ขวาเดินหน้า) |
| 8 | หมุนตัวไปทางขวา |
| 9 | ทุกอย่างหยุด |

## ถ้ามีอะไรผิดปกติ

**ล้อหมุนผิดทาง** สลับสายสองเส้นของมอเตอร์ตัวนั้นที่ driver หรือ
สลับขา direction สองขาของมันใน
[motor.h](../firmware/include/motor.h) (`L_IN1`/`L_IN2` สำหรับล้อ
ซ้าย, `R_IN1`/`R_IN2` สำหรับล้อขวา) แล้ว upload ใหม่ ได้ทั้งสองวิธี ถ้า
ล้อหมุนกลับด้าน*ทั้งสองข้าง* ก็สลับทั้งสองคู่

**ล้อผิดข้างขยับ** มอเตอร์ซ้ายกับขวาของคุณต่อสลับกันที่
driver ให้สลับสองคู่นั้น

**ไม่มีอะไรขยับเลย แต่ Serial Monitor ปกติดี** ESP32 รันได้สบาย ๆ
ด้วยไฟจาก USB แต่มอเตอร์ไม่มีไฟเลย เช็กว่าต่อแบตเตอรี่แล้วและเปิดสวิตช์แล้ว

**มอเตอร์มีเสียงหึ่ง ๆ แต่ไม่หมุน** แรงไม่พอจะเอาชนะแรงเสียดทาน
เปิด [motor.h](../firmware/include/motor.h) แล้วเพิ่มค่า `MIN_DUTY`
ทีละนิดจนกว่ามอเตอร์จะหมุน

**บอร์ดรีสตาร์ทตัวเองอยู่เรื่อย ๆ** มอเตอร์ดึงกระแสมากกว่าที่
แหล่งจ่ายไฟจะให้ได้ แรงดันเลยตก ใช้แบตเตอรี่แยกสำหรับมอเตอร์
และเช็กว่าต่อกราวด์ร่วมกันแล้ว
([03-hardware.md](03-hardware.md))

**มีล้อขยับแค่ข้างเดียวตลอด** ส่วนใหญ่เป็นเพราะขาใน
[motor.h](../firmware/include/motor.h) ไม่ตรงกับที่คุณต่อสายไว้ --
เทียบทีละขากับตารางใน
[03-hardware.md](03-hardware.md) จากนั้นเช็กสายสามเส้นของล้อข้างนั้น
ที่ driver และ jumper ENA/ENB บน L298N

## วัดขนาดหุ่นของคุณ

ระหว่างนี้ เปิด [motor.h](../firmware/include/motor.h) แล้วตั้งค่า:

```c
#define WHEEL_BASE 0.15f   // metres between the two wheels
```

วัดจากกึ่งกลางยางล้อหนึ่งไปถึงกึ่งกลางยางอีกล้อ ถ้าค่านี้
ผิด หุ่นก็ยังวิ่งได้ แต่สั่ง "เลี้ยว 90 องศา" มันจะไม่เลี้ยว 90
องศา
