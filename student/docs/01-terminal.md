# 1. การใช้งาน terminal เบื้องต้น

การทำงานทั้งหมดใน ROS 2 ดำเนินการผ่าน terminal

เปิด terminal ด้วย **Ctrl+Alt+T** สำหรับใน VS Code ให้ใช้ **Ctrl+`** (ปุ่มที่อยู่เหนือปุ่ม Tab)

## คำสั่งพื้นฐานหกคำสั่ง

| | |
|---|---|
| `pwd` | แสดงตำแหน่งปัจจุบัน |
| `ls` | แสดงรายการไฟล์และโฟลเดอร์ในตำแหน่งปัจจุบัน |
| `cd folder` | เข้าสู่โฟลเดอร์ |
| `cd ..` | ย้อนกลับขึ้นไปหนึ่งระดับ |
| `cat file` | แสดงเนื้อหาของไฟล์ |
| `clear` | ล้างหน้าจอ |

ให้ทดลองรันคำสั่งต่อไปนี้:

```bash
cd ~/AI-Camp
pwd
ls
cd docs
ls
cat 01-terminal.md
cd ..
```

## ปุ่มช่วยเหลือสองปุ่ม

**Tab** ใช้เติมคำสั่งหรือชื่อไฟล์ให้สมบูรณ์ ตัวอย่าง: พิมพ์ `cd doc` แล้วกด Tab
ระบบจะเติมส่วนที่เหลือให้โดยอัตโนมัติ ควรใช้เป็นประจำ เนื่องจากช่วยป้องกันการพิมพ์ชื่อโฟลเดอร์ผิด

**ลูกศรขึ้น** ใช้เรียกคำสั่งล่าสุดกลับมา เพื่อรันคำสั่งเดิมซ้ำโดยไม่ต้องพิมพ์ใหม่

## Ctrl+C

ใช้สำหรับหยุดโปรแกรมที่กำลังทำงานอยู่ โปรแกรม ROS 2 จะทำงานต่อเนื่องจนกว่าจะได้รับคำสั่งให้หยุด
จึงต้องใช้ปุ่มนี้เป็นประจำ

หากกด Ctrl+C แล้วโปรแกรมไม่หยุด แสดงว่าโปรแกรมค้าง ให้ปิดแท็บ terminal นั้น
แล้วเปิด terminal ใหม่

## การเปิดหลาย terminal พร้อมกัน

การใช้งาน ROS 2 โดยทั่วไปจะรันหนึ่งโปรแกรมต่อหนึ่ง terminal และรันทุกโปรแกรมพร้อมกัน
ใน VS Code ให้คลิก **+** ที่แผง terminal เพื่อเปิด terminal ใหม่ และคลิกเพื่อสลับระหว่าง terminal

ในบทที่ 5 จะมี terminal เปิดอยู่พร้อมกันสามถึงสี่หน้าต่าง ซึ่งเป็นการใช้งานตามปกติ

## คำสั่งที่จำเป็นต้องรัน

```bash
source /opt/ros/jazzy/setup.bash
```

(ใช้ `jazzy` บน Ubuntu 24.04 และ `humble` บน 22.04 -- หากไม่แน่ใจ
ให้ตรวจสอบด้วยคำสั่ง `ls /opt/ros`)

คำสั่งนี้กำหนดให้ terminal ทราบตำแหน่งของ ROS 2 **ทุก terminal ที่เปิดใหม่ต้อง
รันคำสั่งนี้** หากไม่รัน คำสั่ง `ros2` ทั้งหมดจะแสดงข้อความ "command not found"

หลังจาก build workspace แล้ว ต้องรันอีกหนึ่งบรรทัด:

```bash
source ~/AI-Camp/ros2_ws/install/setup.bash
```

ดังนั้นต้องรันสองบรรทัดนี้ในทุก terminal ทุกครั้ง
เพื่อลดขั้นตอนดังกล่าว ให้เพิ่มคำสั่งไว้ในไฟล์ที่ shell อ่านเมื่อเริ่มทำงาน:

```bash
echo "source /opt/ros/jazzy/setup.bash" >> ~/.bashrc
echo "source ~/AI-Camp/ros2_ws/install/setup.bash" >> ~/.bashrc
```

บน 22.04 ให้ใช้ `humble` แทน `jazzy` โปรเจกต์อยู่ที่
`~/AI-Camp` และทุกบทเรียนใช้ path นี้

เมื่อดำเนินการแล้ว terminal ที่เปิดใหม่จะรันคำสั่งเหล่านี้โดยอัตโนมัติ (`>>` คือการเพิ่มบรรทัดต่อท้าย
ไฟล์ ส่วน `>` คือการ *เขียนทับ* ทั้งไฟล์ -- ต้องใช้ด้วยความระมัดระวัง)

### ข้อยกเว้นหนึ่งกรณี

การ source ROS 2 ไว้ในทุก terminal ถูกต้องสำหรับงานทั้งหมดที่ดำเนินการบน
คอมพิวเตอร์ ยกเว้นงานเดียว คือ **การ build firmware ของหุ่นยนต์**
ในบทที่ 5

การ build ดังกล่าวจะ compile เครื่องมือ build ของ ROS ชุดเฉพาะของตนเอง และ
workspace ที่ source ไว้จะรบกวนกระบวนการนี้
`scripts/build_firmware.sh` จะล้างค่าตัวแปร ROS ให้โดยอัตโนมัติ และบทเรียนจะกำหนดให้ใช้
สคริปต์นี้ในการ build ทุกครั้ง

## การตรวจสอบการใช้งาน

เปิด terminal **ใหม่** แล้วรันคำสั่ง:

```bash
ros2 --help
```

หากแสดงหน้า help แสดงว่าพร้อมใช้งาน หากแสดงข้อความ "command not found"
แสดงว่าบรรทัด `source` ไม่ได้ทำงาน
